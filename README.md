## Descrição

Sistema de compras para a loja PC Mania consite em selecionar computadores de diferentes promoções e armazenar os computadores escolhidos.
Ao final é mostrado as informações do cliente e o valor total da compra.

## Uso de Inteligência Artificial

Foi utilizado o ChatGPT-5, como apoio durante o desenvolvimento do projeto.
A primeira coisa foi colocar o código em desenvolvimento e pedir o que foi descrito nos prompts.

Os Prompts utilizados foram:

1. "Como adicionar objetos de uma classe em um vetor dentro de outra classe?"
2. "Como percorrer um vetor de computadores para calcular o valor total da compra?"
3. "Como criar e chamar um método estático que recebe um vetor de computadores?"

O resultado foi satisfatório para solucionar algumas dúvidas de programação e deu a solução de forma clara.
